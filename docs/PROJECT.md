# Proyecto

## Resumen

Puntadas es un proyecto web para un negocio de productos textiles y deco home.
El sistema debe funcionar como vidriera/e-commerce, permitir explorar productos
con filtros y presentar una identidad visual limpia, calida y orientada a hogar.

## Negocio

- Nombre del negocio: Puntadas.
- Rubro: textil, deco home y productos para el hogar.
- Ubicacion: por definir.
- Canales actuales de atencion: por definir.
- Personas que administran el negocio: por definir.

## Objetivo Principal

Crear una herramienta digital util para mostrar productos, facilitar consultas o compras,
y ordenar la experiencia de clientes del negocio.

## Usuarios

- Administradora/duena: persona del negocio que carga o gestiona productos.
- Clientes: personas que navegan productos, filtran opciones y consultan/compran.
- Otros roles: por definir.

## Alcance Inicial

El alcance inicial se definira en `docs/ROADMAP.md` como MVP.

## Criterios Generales

- Debe ser facil de usar.
- Debe funcionar bien en celular.
- Debe evitar complejidad innecesaria.
- Debe estar documentado para poder retomarlo sin reconstruir contexto desde cero.
- Debe cuidar la privacidad de datos reales del negocio y de usuarios.
- Debe servir como proyecto real de portfolio sin exponer informacion sensible.
